Equilíbrio de Hardy-Weinberg

Modelo populacional

A frequência alélica é p para A e q para a. No equilíbrio, AA = p², Aa = 2pq e aa = q².

Interpretação

Ferramenta de comparação

O equilíbrio de Hardy-Weinberg é um modelo nulo. Se as frequências observadas na população real se afastam dele, algo pode estar alterando o pool gênico.

Conexões ENEM
